# Final Term Project

A Unity arcade game project by **Kuwarpreet Singh**.

## Project contents

- `Assets/` — scenes, scripts, models, textures, audio, and other game assets
- `Packages/` — Unity package manifest and dependency lock file
- `ProjectSettings/` — Unity project configuration

## Open in Unity

1. Install Unity Hub and the Unity Editor version compatible with this project.
2. In Unity Hub, choose **Add** and select this repository folder.
3. Open the project and let Unity import its assets.

## Notes

Unity-generated folders such as `Library/`, `Temp/`, and `Logs/` are excluded because Unity recreates them locally. The imported `UNS_HDRI.hdr` skybox file is also excluded because it is larger than GitHub's 100 MB per-file limit. The project may need that asset restored separately for the original skybox appearance.
